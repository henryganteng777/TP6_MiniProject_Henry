# Agenda Tugas Siswa

## Identitas
- Nama: Henry Santosa
- Kelas: XI TIP 2
- Mata Pelajaran: Pemrograman Mobile

## Deskripsi
Aplikasi Agenda Tugas Siswa dibuat menggunakan Kotlin Console untuk latihan pemrograman dan pengelolaan menu.

## Fitur
1. Menampilkan menu utama.
2. Melihat daftar tugas.
3. Menambahkan tugas.
4. Validasi pilihan menu.
5. Keluar dari aplikasi.

## Teknologi
- Kotlin
- IntelliJ IDEA
- Git
- GitHub

## Cara Menjalankan
1. Buka project di IntelliJ IDEA.
2. Buka file Main.kt.
3. Klik Run.
4. Masukkan pilihan menu.
